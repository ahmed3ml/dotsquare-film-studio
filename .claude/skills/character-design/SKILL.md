# Character Design

Prerequisite: GATE-03 APPROVED. Output: `CHARACTER_BIBLE.md` (GATE-04 with ENVIRONMENT_BIBLE + VISUAL_STYLE_GUIDE).

## Per character (`CH-001…`)
- Role, historical basis (HC-ids), age range in the story, status/rank.
- **Identity lock** — face shape, eyes, brow, nose, beard/hair style and colour, skin tone, build, height
  relative to others, distinguishing marks. Write one 40–60 word **Identity Prompt** reused verbatim in
  every generation (plus a negative list).
- **Wardrobe by scene** — garments, layers, colours, fabrics, wear/dirt/blood progression, headwear,
  footwear; period-plausible per HISTORICAL_BIBLE; mark confidence (documented/plausible/invented).
- Weapons & accessories with `PR-ids`; which hand, how carried.
- Reference sheet requirements: front/3-4/profile/full-body/expression set; asset IDs `AS-xxxx` once real
  images exist — never list assets that do not exist.
- Voice notes for sound-direction (age, register, accent intent in English).

## Rules
- Distinct silhouettes and colour codes so faces/uniforms stay distinguishable in wide shots.
- Depiction constraints: do not depict the Prophet Muhammad; for other revered historical figures, apply
  the policy recorded in PROJECT.md Open Decisions — if undecided, ask the human first.
- Identity changes after GATE-04 require `revise`. Record reference images by hash in the bible.
- No living-person likeness without client authorization.
